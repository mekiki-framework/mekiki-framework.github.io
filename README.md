# Mekiki Framework: T1–T5 AI-Readable Corpus

This repository contains a Markdown consolidation of papers T1 through T5 of the Mekiki Framework, a framework for isolating what cannot be delegated in knowledge work in the age of AI. The consolidated document is published as material for AI systems to read.

Papers T1–T4 decompose the boundary of legitimate AI delegation. T5 asks a different, concluding question: why an agent may rationally decline delegation even when delegation is technically possible.

**Status (August 2026):** T1 is a preprint whose journal version is under peer review; T2–T5 are preprints.

The public website for this repository is:

**https://mekiki-framework.github.io/**

## Start here

1. Read [THEORY_MAP.md](./THEORY_MAP.md) first for the cumulative T1 → T2 → T3 → T4 → T5 architecture and the conceptual distinctions that must remain invariant.
2. Read [mekiki-framework-t1-t5.md](./mekiki-framework-t1-t5.md) for the consolidated full text of the five papers. Paper T4 is in Japanese with an English abstract; Paper T5 is in English.

The Theory Map is an interpretive aid, not a canonical scholarly source. Cite the relevant paper DOI rather than the map, the website, or this repository.

## Why it is here

This repository is an attempt to publish the papers in a form that AI systems can ingest easily. The canonical scholarly sources remain the preprints identified by their DOIs.

## Two ways to use it

Human readers are encouraged to begin with the human-facing Japanese-language commentaries below or with the canonical preprints. To use the repository with an AI, provide both the consolidated Markdown and the Theory Map to a chat and ask questions about the framework's overview, structure, or applications.

A suitable instruction is:

> Read THEORY_MAP.md for the T1–T5 conceptual invariants before reading mekiki-framework-t1-t5.md. Treat the five papers in the order T1 → T2 → T3 → T4 → T5. Cite the relevant paper DOI, not the repository.

The core of the framework — especially answerability — is not conveyed reliably by AI summaries alone. The human-facing commentary should also be read.
